---
description: "Approve a balanced journal as a second person"
---

Read CLAUDE.md. Run `npm run close -- approve-journal --journal=... --actor=...`. Ask for any value you do not have; never guess one.

Check the journal balances and has evidence before approving. The approver must be a different person from the preparer.

Every write needs --actor: the name of the person doing it, for the history.

Never send anything. Drafts go to drafts/ for a person to send. Never invent a balance, an explanation or an approval.
