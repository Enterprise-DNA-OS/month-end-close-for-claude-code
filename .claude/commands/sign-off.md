---
description: "Sign off a completed close task as a second person"
---

Read CLAUDE.md. Run `npm run close -- sign-off --task=... [--period=...] --actor=...`. Ask for any value you do not have; never guess one.

Sign-off must be by a different person from whoever completed the task.

Every write needs --actor: the name of the person doing it, for the history.

Never send anything. Drafts go to drafts/ for a person to send. Never invent a balance, an explanation or an approval.
