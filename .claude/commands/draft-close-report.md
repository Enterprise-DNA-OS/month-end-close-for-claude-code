---
description: "Draft the close report for the finance lead or board"
---

Read CLAUDE.md. Run `npm run close -- draft-close-report --period=...`. Ask for any value you do not have; never guess one.

Never present a period as closed unless its state is closed.

Every write needs --actor: the name of the person doing it, for the history.

Never send anything. Drafts go to drafts/ for a person to send. Never invent a balance, an explanation or an approval.
