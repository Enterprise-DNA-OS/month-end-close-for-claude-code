description: "Close a period once everything is finished"
---

Read CLAUDE.md. Run `npm run close -- close-period --period=... --actor=...`. Ask for any value you do not have; never guess one.

If it refuses, list what is still open and who owns each item. Never mark items done to get a period closed.

Every write needs --actor: the name of the person doing it, for the history.

Never send anything. Drafts go to drafts/ for a person to send. Never invent a balance, an explanation or an approval.
