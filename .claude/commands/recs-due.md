Read CLAUDE.md. Run `npm run close -- recs-due --json`.

Present the result as a short table with the numbers that matter. An empty list means no matching records, not that everything is fine.

Lead with high-risk accounts and anything late. A balance that moved after review needs reconciling again.

Never send anything. Drafts go to drafts/ for a person to send. Never invent a balance, an explanation or an approval.
