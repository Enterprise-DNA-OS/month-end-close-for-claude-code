---
description: "Draft the weekly close review from four commands"
---

Read CLAUDE.md. Run `npm run close -- weekly-review`. Ask for any value you do not have; never guess one.

Open the draft and summarise it in five lines: where the close stands, what is late, who has most, what the auditor is waiting on.

Every write needs --actor: the name of the person doing it, for the history.

Never send anything. Drafts go to drafts/ for a person to send. Never invent a balance, an explanation or an approval.
