---
description: "Record a journal as posted in the ledger"
---

Read CLAUDE.md. Run `npm run close -- post-journal --journal=... --ledger-ref=... --actor=...`. Ask for any value you do not have; never guess one.

Post in the ledger first, then record the ledger reference here.

Every write needs --actor: the name of the person doing it, for the history.

Never send anything. Drafts go to drafts/ for a person to send. Never invent a balance, an explanation or an approval.
