---
description: "Prepare a balance sheet reconciliation"
---

Read CLAUDE.md. Run `npm run close -- reconcile --account=... [--period=...] --supporting=amount --evidence=... --actor=...`. Ask for any value you do not have; never guess one.

Ask for the supporting balance (bank statement, aged ledger, loan statement, stocktake) and where the evidence lives. Enter the supporting balance with the ledger sign: liabilities negative. Report the unexplained amount.

Every write needs --actor: the name of the person doing it, for the history.

Never send anything. Drafts go to drafts/ for a person to send. Never invent a balance, an explanation or an approval.
