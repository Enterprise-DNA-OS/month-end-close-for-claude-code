---
description: "Open a new month and copy in the close checklist"
---

Read CLAUDE.md. Run `npm run close -- open-period --entity=... --month=YYYY-MM --actor=...`. Ask for any value you do not have; never guess one.

Run it on the first business day after month end, then show close-status.

Every write needs --actor: the name of the person doing it, for the history.

Never send anything. Drafts go to drafts/ for a person to send. Never invent a balance, an explanation or an approval.
