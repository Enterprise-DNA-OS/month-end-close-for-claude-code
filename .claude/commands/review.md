---
description: "Review a reconciliation as a second person"
---

Read CLAUDE.md. Run `npm run close -- review --account=... [--period=...] --actor=...`. Ask for any value you do not have; never guess one.

The reviewer must be a different person from the preparer. Never review on the operator's behalf with someone else's name.

Every write needs --actor: the name of the person doing it, for the history.

Never send anything. Drafts go to drafts/ for a person to send. Never invent a balance, an explanation or an approval.
